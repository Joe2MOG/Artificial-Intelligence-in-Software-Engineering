# AI: Dynamic Web Lab Generation for Core CSS Concepts

## Overview

This task explores core CSS concepts using AI-generated interactive web applications. I used Gemini Canvas to generate a Box Model visualizer, refine it with more detailed controls, and build a separate Flexbox and Grid playground.

The goal was not only to generate code, but to interact with the tools and observe how CSS properties affect layout in real time.

## Files

- `box-model-initial.html` - Initial CSS Box Model and display visualizer.
- `box-model-refined.html` - Refined Box Model visualizer with individual controls for padding, margin, and border on each side, plus border radius.
- `flexbox-grid-playground.html` - Interactive playground for experimenting with Flexbox and CSS Grid.

## AI Tool Used

Gemini Canvas

## Box Model Lab

The initial lab includes controls for width, padding, border width, margin, and display.

The display property can be changed between `block`, `inline-block`, and `inline`.

The refined version adds separate controls for the top, right, bottom, and left sides of padding, margin, and border. It also adds a border-radius control.

## Flexbox and Grid Playground

The Flexbox and Grid playground allows experimentation with:

- `display`
- `flex-direction`
- `justify-content`
- `align-items`
- `grid-template-columns`

The interface updates the layout in real time when a property changes.

## Key Learning

The interactive labs helped make CSS layout concepts easier to understand because I could immediately see the effect of changing a property. Instead of only reading definitions of padding, margin, display, Flexbox, and Grid, I could manipulate the values and observe how the browser recalculated the layout.
